# 01. Contexto del Proyecto - E-commerce de Importación (Estilo Nike)

## Descripción General
Plataforma web de comercio electrónico y gestión de inventario para la venta de productos importados desde Estados Unidos Originales hacia Guatemala. Cuenta con un catálogo público para clientes y un panel de administración privado para el control de stock, precios y gestión de pedidos.

## Modelo de Negocio & Operación
- **Origen de productos:** Importados desde Estados Unidos Originales.
- **Inventario:** Stock local disponible en Guatemala. Los productos se actualizan en tiempo real conforme se venden o se agregan nuevos lotes de importación.

## Stack Tecnológico Requerido
- **Framework:** Next.js (App Router)
- **Estilos:** Tailwind CSS
- **Base de Datos & Auth:** Supabase (PostgreSQL + Storage para imágenes)
- **Despliegue:** Vercel
